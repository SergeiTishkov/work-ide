# KISEL — спокойная легаси-удалёнка на неполный день

> **KISEL = Keep It Simple, Easy, Legacy.**
>
> По-русски читается как «кисель» — и это ровно та ирония, ради которой имя
> выбрано: что-то тягучее, мутное, слегка сладковатое, но не очень, и
> мееедленное. Именно такую работу этот поиск и ищет.
> Спокойная, асинхронная, легаси-работа на неполный день.
>
> Аббревиатура намеренно называет **смысл поиска**, а не человека и не стек:
> идентичность переживёт смену технологий, а «ищу тихую легаси-работу на неполный день»
> останется собой. Пишется через `k`, чтобы `grep kisel_` не тонул в тексте
> вакансий, где полно слова *calm*.

## Что это за идентичность

Поиск занятости на **неполный день**. Это переворачивает обычную
логику найма: здесь не нужны интересные задачи, рост и амбициозные проекты —
основная работа их уже полностью закрывает. Нужна предсказуемая, скучная,
хорошо документированная рутина на 2–4 часа в день, которую можно делать
спокойно и с активной помощью AI.

Отсюда все настройки, которые со стороны выглядят странно: `legacy`,
`mainframe`, `cobol`, `enterprise`, `bank`, `government` — это **плюсы**, а
`greenfield`, `fast-paced`, `startup`, `move fast` — минусы. Обычный джоб-серч
устроен ровно наоборот.

## Для кого

Senior .NET/C# инженер, 7+ лет, живёт в **Грузии (страна на Кавказе)**.

**Постоянная ловушка**: в вакансиях «Georgia» почти всегда означает штат США.
Система различает эти случаи по контексту (`ambiguous_place_names` в
`kisel_criteria.yaml`), но при ручной проверке об этом нужно помнить всегда.

### Жёсткие дисквалификаторы (0% шанс, не «низкий приоритет»)

Все реализованы как гейты в `score.py`, а не как штраф в баллах. Урок, купленный
опытом: мягкий штраф тонет в общих словах бойлерплейта, и вакансия всё равно
всплывает в выдаче.

1. **Не удалённая работа.** По умолчанию вакансия должна быть *подтверждена* как
   remote. Отсутствие любого remote-сигнала — отказ, а не «неизвестно, но пусть».
2. **Жёсткое требование резидентства не в Грузии.** `US only`, `remote LATAM`,
   `Canada only`, **`EU Remote`** (Грузия не в ЕС!) — всё это одинаково
   недоступно. Список принципиально неполон — стран бесконечно много.
3. **Требование языка кроме русского и английского.** Немецкий, французский и
   т.п. — отказ. Вакансии, целиком написанные не по-английски/по-русски, тоже
   (немецкие джоб-борды дают их массово).
4. **Роль не про разработку ПО.** CFO, Product Manager, Sales, Customer Support,
   Recruiter, Webmaster… а также **DevOps/SRE/платформа/инфраструктура** —
   человек прикладной разработчик, а не инженер эксплуатации.
5. **Стек не .NET/C# и не JS/TS.** Случайного совпадения по одному
   второстепенному слову недостаточно. Java/Scala сами по себе — нет (на Java
   web-позицию не возьмут), **но Java/Scala для дата-пайплайнов** (Spark,
   Databricks, ETL) — желанный вариант, реальный опыт есть.

### География

США/Канада — «мечта» (высокий потолок оплаты, низкая вероятность).
Израиль/ОАЭ — равноценная реалистичная цель, не «план Б хуже»: потолок ниже
(~$5k/мес), вероятность найма выше. По Израилю уже есть реальный опыт работы.

Важно не путать «компания базируется в X» (нейтрально) с «нужно резидентство в
X» (дисквалификация). Эта разница стоила одной итерации отладки.

### Деньги против спокойствия

Ориентир: **$5000–8000/мес** при 2–4 часах в день. $7–8k предпочтительнее, но
**не в ущерб спокойствию**: гарантированно скучная работа за $5k лучше
стрессовой за $8k.

Поэтому в `kisel_criteria.yaml` вес `low_intensity_signal` (20, разброс ±20)
вдвое больше веса `compensation_signal` (10, разброс ~+2..+10). Это осознанное
решение, а не оверсайт — не «чинить».

## Что значит «простая работа» для этого скиллсета

Разобрано по CV, по фактической частоте технологий в 8 последних ролях
(2018–2026). Скиллсет меняется медленно, поэтому зафиксирован здесь, а не
пересчитывается каждый запуск.

**Простое** (6–8 ролей из 8 — буквально ежедневная работа 7+ лет):
C#, .NET / .NET Core / .NET Framework, ASP.NET (MVC / Web API / Core),
SQL Server, Angular / AngularJS.

**Уверенно, но не постоянно** (2–4 роли): Entity Framework (EF6 / EF Core),
TypeScript / JavaScript, React, Azure, Docker, микросервисы, CQRS, DDD, Event
Sourcing, HTML/CSS.

**Периферийное** (1–2 роли за карьеру — реальный, но узкий опыт): Node.js,
MongoDB, Cosmos DB, DynamoDB, Apache Spark, Databricks, Delta Lake, Python,
jQuery, SOAP, XSLT, PHP, GraphQL, DevExpress, Scala, Java, NgRx, Redux, MobX.

**Чего в CV нет**, вопреки первой версии профиля: WebForms, VB.NET, Classic ASP.
Они остаются полезным сигналом «вакансия про легаси», но **не дают личный
stack-бонус** — это две разные оси, и путать их нельзя.

### Легаси ≠ простое: отдельная ось

Легаси-поддержка в банке и R&D-команда в том же банке — разные вещи. Роль может
быть напичкана словами `enterprise`/`banking` из описания компании и при этом
быть исследовательской.

Красные флаги (гейт `role_complexity_signal`): в названии — Principal/Staff
Scientist, Research/Applied Scientist, ML Engineer, Founding Engineer, всё с
«Agentic»; в описании — build from scratch, greenfield, 0 to 1, own the entire
architecture, cutting-edge, PhD required.

Реальные примеры, из-за которых правило появилось: «Staff Software Engineer,
Agentic Platform» в необанке tide и «Principal Machine Learning Scientist» в
tripadvisor — обе набирали хороший балл за банковский контекст компании.

## Какие инструменты и источники использует

Полный список — `kisel_sources.yaml`, каталог возможностей — `docs/BUILDING_BLOCKS.md`.

| Инструмент | Как используется |
|---|---|
| Все 5 remote-бордов (WWR, RemoteOK, Remotive, Jobicy, Himalayas) | Включены. WWR — лучший по сигнал/шум |
| ATS-доски компаний | Включены; список компаний в `kisel_ats_targets.yaml` — **главный рычаг качества**, наполнять зрелым энтерпрайзом |
| HN «Who is hiring» | Включён с явными словами `.NET, C#, ASP.NET, legacy, SQL Server` |
| arbeitnow | Включён осознанно, несмотря на ~6% полезного выхода |
| Ручной ввод (`ingest_manual.py`) | **Важен особенно**: публичные борды слабо покрывают комбинацию «легаси + worldwide remote + высокая ставка» |
| `company_intel.py` | Используется: возраст компании по Wikidata (10+ лет — плюс) |
| `kb.py set-company-reputation` | Используется: репутация с Glassdoor через веб-поиск, WLB важнее общего рейтинга |
| `link_check.py` | Используется: мёртвые ссылки (404/410) не показываются |
